# DSA Solutions

This repository contains my solutions to various **Data Structures and Algorithms (DSA)** problems that I have solved while learning and practicing problem-solving.

The solutions are mainly written in **C++** and are based on problems from platforms like **LeetCode**.

### Purpose

This repository is primarily for my own learning and revision. I upload the problems I solve so I can keep track of my progress and easily revisit them later.

I have also added **simple comments and notes inside the code** to help me quickly remember the approach, logic, and important concepts when revising a problem.

The goal is to continuously practice, improve my problem-solving skills, and build a strong foundation in DSA.
